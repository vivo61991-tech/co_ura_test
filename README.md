# URA · Visão Geral

Resumo da URA do dia no celular: os cards do Registro do Dia, Ativação B2B, Rifaina e COE CAT, o gráfico do Total Geral
(hoje × média) e as falhas massivas abertas.

- Endereço: <https://wro1984.github.io/CO_URA/>
- Entrada: pelo **HUB dos apps** (<https://wro1984.github.io/>), com a mesma matrícula e chave. Quem libera o app é o
  administrador, no MAPI (Comunicação → HUB dos apps).
- Os dados são publicados cifrados pelo MAPI (Comunicação → URA · App). Detalhes para quem mantém: `CLAUDE.md`.

Testes: `npm test`.
